# 📊 Regression Web App

A simple and interactive **Flask web application** that demonstrates regression techniques like **Ridge Regression** and **Lasso Regression**.  
Users can input parameters and instantly view model results and visualizations.

---

## 🚀 Features

- 🔹 Ridge Regression implementation
- 🔹 Lasso Regression implementation
- 🔹 User input via web interface
- 🔹 Displays:
  - Coefficients
  - Mean Squared Error (MSE)
  - R² Score
- 🔹 Graphical visualization of results
- 🔹 Simple and clean UI using Flask templates

---

## 🛠️ Tech Stack

- Python 🐍
- Flask 🌐
- NumPy
- Scikit-learn
- Matplotlib
